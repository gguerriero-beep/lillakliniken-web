# Lillakliniken – webbplats

Statisk webbplats för lillakliniken.com, publicerad med Cloudflare Pages.

- Allt innehåll, priser och Kaddio-länkar finns i `src/build.py`.
- Stil, typsnitt, ikon, omdirigeringar och säkerhetshuvuden finns i `src/static/`.
- Bygg: `python3 src/build.py` (skriver till `public/`).

Cloudflare Pages: build command tomt, output directory `public`.
